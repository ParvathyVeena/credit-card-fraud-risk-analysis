# Credit Card Fraud Risk Analysis – Power BI Dashboard

## Project Overview

This project presents an interactive Power BI dashboard developed to analyze credit card fraud patterns, transaction risks, and fraudulent activity across different categories, states, and months.

The dashboard helps identify fraud trends and high-risk transaction patterns through interactive filters and visualizations.

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## Dashboard Features

The dashboard provides analysis of:

- Fraudulent transaction count
- Fraud rate
- Critical-risk transactions
- Fraudulent transaction amount
- Top fraud type
- Fraud type and transaction category
- Fraud risk distribution
- Fraudulent transactions by state
- Monthly fraud trends

## Data Preparation

Power Query was used for:

- Handling missing values
- Data cleaning and transformation
- Formatting and standardization
- Removing duplicate records
- Preparing data for analysis

A structured data model was created in Power BI to support interactive analysis and reporting.

## Key Visualizations

### Fraud Type and Transaction Category

A stacked bar chart compares the total transaction amount across different fraud types and transaction categories, including:

- Card Not Present
- Card Skimming
- Identity Theft
- Account Takeover
- Phishing

### Fraud Risk Distribution

A donut chart shows the distribution of transactions across different risk levels:

- Low
- Medium
- High
- Critical

### Fraudulent Transactions by State

A bar chart compares fraudulent transaction counts across states.

The dashboard shows higher transaction counts for states such as:

- Maharashtra
- Karnataka
- Rajasthan
- West Bengal
- Uttar Pradesh

### Monthly Fraud Trend

A line chart presents fraudulent transaction counts across different months, helping identify changes and trends over time.

## Key Dashboard Metrics

The dashboard displays:

- Fraudulent Transactions: 286
- Fraud Rate: 28.60%
- Critical Risk Transaction: 10.70
- Top Fraud Type: Card Not Present
